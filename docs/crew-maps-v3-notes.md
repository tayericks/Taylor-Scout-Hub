# Crew Maps V3

- Map print framing starts at the last detected freeway exit and ends at the crew-map destination.
- Directions are generated from the configured approach regions to the destination address.
- Hospital auto-selection only accepts explicitly tagged trauma centers Level I-IV and is measured from the set/location address. If no verified tagged trauma center is available, no hospital is guessed.
- Generated maps start with Crew Parking and Location cards and pull Basecamp/Catering cards from Bible data when available. Users can add/remove/edit additional info boxes.
- Saved maps are grouped/sorted by episode and can be deleted from Crew Maps home.
